# Three-minute judge flow

1. Open the dashboard and point out the visible `DEMO MODE` badge.
2. Search `water` to narrow recent evidence.
3. Open `EVID-014` and show Cloudinary-style media, detected objects, GPS, confidence, and trust score.
4. Open `EVID-011` and explain the honest claim signal: 52 supported households versus 85 claimed.
5. Open `EVID-009` to show missing GPS as `NEEDS REVIEW`, not fraud.
6. Explain the status mix, project pulse, and integration states.
7. Close with: GroundTruth does not only generate an impact story; it shows the evidence behind it.
